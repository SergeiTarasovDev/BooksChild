# Гайды и книги для детей

Проект состоит из двух слоёв: **гайды по практической жизни** и **книжная полка**. Гайды помогают начать разговор о повседневных темах по возрастам **5–8, 8–11, 11–14, 14–19**, а книги дают более глубокий контекст и самостоятельное чтение.

## Принципы

- **Художественные** — формат «почему и как читать»: автор и эпоха, контекст, на что смотреть (язык, структура, приёмы, образы) **без спойлеров**, почему читают до сих пор, «как читать». Это **не пересказ** — смысл книги в слоге, поэтому везде пометка «читать оригинал».
- **Познавательные** — разбор **содержания** по разделам/темам (как у взрослых книг): суть, «Что важно понять», пример из книги, вывод. Объём блока определяется объёмом исходной мысли в разделе, а не числом предложений. Для книг без глав (энциклопедии, опыты) — деление по темам.

## Структура

- `index.html` — оболочка: сначала гайды, затем книжная полка; материалы открываются во вкладках.
- `guides.html` — витрина направлений.
- `guide-money.html` — эталонный гайд о деньгах с четырьмя возрастными уровнями.
- `guide-sleep-food-movement.html` — осторожный образовательный гайд о сне, еде и движении.
- `guide-style.css`, `guide-theme.js` — отдельные стили и логика гайдов; книжный слой использует свои `book-style.css`, `book-theme.js`.
- `catalog.html` — каталог по возрастам (художественные/познавательные).
- `<Книга>.html` — страницы книг.
- `book-style.css`, `book-theme.js` — общие стили и логика.

## Возможности

- Светлая (бежевая) и тёмная (графит) темы.
- Переключение возрастного уровня внутри гайда без перехода на другую страницу.
- Отметки «прочитано» (локально в браузере) и счётчик.
- Прогресс чтения, кнопка «Наверх».
- Верхнее меню (десктоп) / выдвижное (смартфон); в альбомной ориентации смартфона — единая нижняя панель.

## Публикация в интернете (GitHub Pages)

Сайт статический, поэтому гайды и книжная полка публикуются вместе бесплатно за пару минут.

**1. Склонировать репозиторий**

```bash
git clone git@github.com:SergeiTarasovDev/BooksChild.git
cd BooksChild
```

Если SSH-ключ не настроен, используйте HTTPS-ссылку: `https://github.com/SergeiTarasovDev/BooksChild.git`.

**2. Включить GitHub Pages**

- Откройте репозиторий на GitHub → **Settings** → **Pages**.
- **Build and deployment** → Source: **Deploy from a branch**.
- Branch: **main**, папка **/ (root)** → **Save**.
- Репозиторий должен быть **публичным** — на бесплатном тарифе Pages доступны только для публичных репозиториев.

**3. Открыть в любом браузере**

- Через ~1 минуту сайт доступен по адресу `https://sergeitarasovdev.github.io/BooksChild/`.
- Открывается в любом браузере на компьютере, планшете и телефоне — устанавливать ничего не нужно.
- При каждом `git push` в ветку `main` сайт обновляется автоматически.

**Локально без публикации**

Откройте `index.html` двойным кликом — сайт работает и без интернета.

Для проверки перед публикацией:

```bash
node --check guide-theme.js
git diff --check
```

Новые HTML-страницы не требуют сборки или сервера. Публикация выполняется обычным `git push` в ветку `main`; коммит в рамках подготовки этапа 0 не создаётся автоматически.

## Новая концепция: справочник практической жизни

Проект состоит из двух слоёв:

- **Гайды** — главный слой: практические объяснения тем, которым школа и взрослые разговоры часто уделяют мало внимания. Каждый гайд адаптирован для возрастов 5–8, 8–11, 11–14 и 14–19 лет и содержит: зачем знать, как это работает, жизненные примеры, типичные ошибки, пошаговые действия, памятку, вопросы для разговора и книги для углубления.
- **Книжная полка** — художественные и познавательные книги с форматами «почему и как читать» или подробным конспектом. Книги остаются отдельным слоем и служат продолжением гайдов.

### Пилотные гайды

- Как устроены деньги
- Сон, еда и движение
- Эмоции и разговоры
- Цифровая безопасность
- Учёба и время
- Споры и границы
- Выбор профессии
- Как принимать решения и проверять информацию
- Бытовая самостоятельность
- Как устроен компьютер

Возрастные материалы переключаются внутри одного гайда; отдельные копии страниц по каждому возрасту не создаются.
