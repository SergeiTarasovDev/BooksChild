# Книги для детей

Каталог детских книг-конспектов по возрастам: **5–8, 8–11, 11–14, 14–19** — художественные и познавательные.

## Принципы

- **Художественные** — формат «почему и как читать»: автор и эпоха, контекст, на что смотреть (язык, структура, приёмы, образы) **без спойлеров**, почему читают до сих пор, «как читать». Это **не пересказ** — смысл книги в слоге, поэтому везде пометка «читать оригинал».
- **Познавательные** — разбор **содержания** по разделам/темам (как у взрослых книг): суть, «Что важно понять», пример из книги, вывод. Объём блока определяется объёмом исходной мысли в разделе, а не числом предложений. Для книг без глав (энциклопедии, опыты) — деление по темам.

## Структура

- `index.html` — оболочка: меню по возрасту × типу; книги открываются во вкладках.
- `catalog.html` — каталог по возрастам (художественные/познавательные).
- `<Книга>.html` — страницы книг.
- `book-style.css`, `book-theme.js` — общие стили и логика.

## Возможности

- Светлая (бежевая) и тёмная (графит) темы.
- Отметки «прочитано» (локально в браузере) и счётчик.
- Прогресс чтения, кнопка «Наверх».
- Верхнее меню (десктоп) / выдвижное (смартфон); в альбомной ориентации смартфона — единая нижняя панель.

## Публикация в интернете (GitHub Pages)

Сайт статический, поэтому публикуется бесплатно за пару минут.

**1. Склонировать репозиторий**

```bash
git clone git@github.com:SergeiTarasovDev/BooksChild.git
cd BooksChild
```

Если SSH-ключ не настроен, используйте HTTPS-ссылку: `https://github.com/SergeiTarasovDev/BooksChild.git`.

**2. Включить GitHub Pages**

- Откройте репозиторий на GitHub → **Settings** → **Pages**.
- **Build and deployment** → Source: **Deploy from a branch**.
- Branch: **main**, папка **/ (root)** → **Save**.
- Репозиторий должен быть **публичным** — на бесплатном тарифе Pages доступны только для публичных репозиториев.

**3. Открыть в любом браузере**

- Через ~1 минуту сайт доступен по адресу `https://sergeitarasovdev.github.io/BooksChild/`.
- Открывается в любом браузере на компьютере, планшете и телефоне — устанавливать ничего не нужно.
- При каждом `git push` в ветку `main` сайт обновляется автоматически.

**Локально без публикации**

Откройте `index.html` двойным кликом — сайт работает и без интернета.
